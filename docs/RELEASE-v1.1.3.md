### 设置默认折叠

详情窗口主要展示电量、连接状态和其它设备概览，设置区默认收起。点击“设置”展开后可调整选项；每次重新打开详情会再次收起，原有设置保持不变。右键菜单中的设置项也集中到一个“设置”子菜单。

### 按设备和模式显示选项

- 只有一个可用设备时，隐藏显示方式、轮换间隔等多鼠标选项；查询间隔始终可设置。
- 至少两个当前设备在本次运行中成功读到过有效电量时，自动显示多鼠标设置。已有历史读数的休眠设备仍计入，从未成功读取的闲置接收器不会单独开启多鼠标选项。
- 多设备时，固定目标仅在固定模式出现，轮换间隔仅在轮换模式出现。
- 原先选择轮换或平铺时，若只剩一个有读数的设备，临时只显示该设备；保存的模式不变，另一台设备恢复后继续按原模式显示。
- 若保存的固定目标不可用而另一台设备可用，仍提供切换显示设备的入口，避免停留在无法切换的灰色目标上。

设备仍按 USB 电量接口的 ID 区分，不会按相同型号猜测合并物理鼠标。其它设备列表、低电通知、已保存的选项和 **30 秒默认查询间隔**均保留；没有增加硬件查询或计时器。
